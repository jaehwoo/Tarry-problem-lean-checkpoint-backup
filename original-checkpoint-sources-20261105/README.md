# Lean sources recovered from nested checkpoints

This supplement contains 112 distinct Paper I Lean source texts recovered from nested checkpoint archives. Each file preserves the saved bytes. [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json) gives its SHA-256 and the chain of archive member names leading to the original source.

These are historical sources, including proof attempts, integration files, and audit scripts. They are archived for reference and were not recompiled for this upload.

The earlier [source-and-report archive](../formalization-archive-20261105/) contains the current source snapshot and additional historical material. This supplement contains Lean source and provenance only.
