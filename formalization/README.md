# Tarry Lean formalization sources

This is the 5 November 2026 saved source snapshot: 557 Lean modules. The 554 reused module sources match the SHA-256 hashes recorded in the latest fixed-a net stage; its three new modules are included unchanged. `SOURCE_INDEX.json` records original artifact names, member paths and byte hashes.

This upload is archival. It does not constitute a new compilation or a proof of the manuscript main theorem. Consult the saved verification PDFs for the scope, retained assumptions and unresolved obligations of each result. The source directory alone does not assemble the pinned dependency environment.

The source-and-report package also preserves 3,898 distinct historical source texts and 207 original verification PDFs. Historical source texts include intermediate attempts and are not all certified proofs. Two original build-evidence ZIPs had unreadable ZIP directories, as recorded in the package summary. Historical checkpoints 72–75 remain unconfirmed.

The broader archive of correspondence, checklists, build logs, compiled products and checkpoint containers remains pending publication approval. The existing archive releases have not been modified.
